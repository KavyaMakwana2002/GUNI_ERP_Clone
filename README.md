## 🚀 Installation and Setup

Follow these steps to run the project on your computer.

### 1. Prerequisites

Install the required tools:

- [Git](https://git-scm.com/)
- [Visual Studio Code](https://code.visualstudio.com/)
- The runtime and dependencies required by the project

### 2. Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/KavyaMakwana2002/GUNI_ERP_Clone.git
```

### 3. Open the Project

```bash
cd GUNI_ERP_Clone
code .
```

### 4. Install Dependencies

If the project uses Node.js, run:

```bash
npm install
```

### 5. Run the Project

For a Node.js project, check `package.json` and run the available development script. For example:

```bash
npm run dev
```

Open the local URL displayed in your terminal.

**Note:** The commands depend on the project's actual technology stack and configuration.
