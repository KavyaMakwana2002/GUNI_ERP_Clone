Logic Development with Programming – II

BCA (Hons) – Semester II

Subject Code: U32A1LDP | Academic Year: 2024-25

Credits: 4 (L-2, P-2)

Teaching & Examination Scheme
  • Lecture: 2 Hours per week
  • Practical: 4 Hours per week
  • Total Hours: 6
  • Theory: CE – 50 | SEE – 50 | Total – 100 Marks
Objective

By the completion of this course, students will be able to implement, test, debug, and document programs, Program with pointers and arrays, perform pointer arithmetic, and use the preprocessor, Understand how to write and use functions, how the stack is used to implement function calls, and parameter passing options, Understand and use the common data structures typically found in C programs — namely arrays, strings, lists, trees, and hash tables.

Pre-requisites

Need to know about the basics of the C programming language. Students need to understand the basic concepts like data type, variable, constant, control statement with structure of programming language need to understand before going for advanced concepts.

Course Outcomes (CO)
  • CO1: Design, implement, test and debug programs that use arrays.
  • CO2: Design, implement, test and debug programs that use character strings arrays and that use pointers for character strings.
  • CO3: Design, implement, test and debug programs that use functions.
  • CO4: Implement test and Store different data types in the same memory.
  • CO5: Analyze programming problems to choose when regular loops should be used and when recursion will produce a better program.
